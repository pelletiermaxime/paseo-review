# Workspace Review

A standalone review tab for Paseo 0.12.0: searchable changed-file tree, scrollable unified/split diffs, persistent per-file Viewed markers, minor inline edits with explicit Save and Cancel, and line comments sent to a selected workspace agent as code-review feedback.

The current comparison is HEAD to the worktree, including staged, unstaged and untracked files. GitLab review state is separate. Native clients show a desktop/web fallback. See README.md for bounds, read-only targets, draft lifetime and verification evidence.
