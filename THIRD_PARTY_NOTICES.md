# Third-party notices

Workspace Review uses [Pierre Diffs](https://github.com/pierrecomputer/pierre/tree/main/packages/diffs) for diff rendering, inline editing, and its portable syntax-highlighting worker. Our plugin code is licensed under [MIT](LICENSE); the components below retain their own licenses.

## Changes to upstream code

- `patches/@pierre__diffs@1.5.2.patch` modifies Pierre 1.5.2 to keep only the default dark/light themes and the JavaScript highlighting engine.
- `scripts/build-diff-worker.mjs` derives `client/diff-worker.generated.json` from Pierre 1.5.2's portable worker, removing its unused Oniguruma/WASM backend and source-map reference. Its bundled dependency versions come from that upstream asset and can differ from the installed renderer dependencies.
- The default Pierre themes include the upstream attribution to Primer's GitHub VS Code theme. That notice and its MIT license are retained in [LICENSES/pierre-theme-NOTICE.txt](LICENSES/pierre-theme-NOTICE.txt).
